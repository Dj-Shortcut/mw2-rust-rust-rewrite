# MW2 / Rust-style rewrite project

This repository is the handoff point for the game rewrite being developed in
the separate Sol session.

## Intended direction

- A fully independent rewrite, not a redistribution of original game assets.
- MW2-inspired gameplay and weapon handling.
- Rust-style building, maps, inventory and survival systems.
- Skateboarding elements may be added where technically and legally suitable.

## Handoff rule

Sol should place the completed, reviewable product in this repository when the
current implementation is finished. Do not add proprietary game assets or
files copied from an original game installation.

## Current status

The repository is intentionally empty apart from this project brief. The
first delivered version should include build/run instructions and a clear
description of what is actually implemented.
